# Idlery and CoreCredit — website sources

The static sources for **two** sites, plus the four public CoreCredit pages that
were the original contents of this repository.

| Path | Becomes | Netlify archive |
|---|---|---|
| `sites/idlery/` | <https://idlery.com> | `idlery-netlify.zip` |
| `sites/corecredit/` | <https://corecredit.idlery.com> | `corecredit-netlify.zip` |

Each archive extracts with `index.html` at its root and is dragged onto its own
Netlify site. **`DEPLOYMENT-INSTRUCTIONS.md` is the procedure** — sites, domains,
DNS, certificates, what to check afterwards, and how to regenerate the assets.

The four files at the repository root (`index.html`, `support.html`,
`privacy.html`, `terms.html`) are the GitHub Pages copies of the public support
and legal pages, kept as a fallback origin. They are generated by
`docs/tools/render_legal_pages.py` in the application repository from the same
text the app shows on device, and are refreshed from it — the copies here now
carry `support@idlery.com` and the `corecredit.idlery.com` addresses, matching
`AppConfiguration` in the shipping build. The pages actually served at
`corecredit.idlery.com/support`, `/privacy` and `/terms` are the fuller ones
under `sites/corecredit/`.

CoreCredit is published by **Idlery Services LLC** and is available on the App
Store: <https://apps.apple.com/app/corecredit-core-return-ledger/id6802336957>

## Building and checking

```
bash build/verify.sh          # serve both sites with their real headers, run every check
python3 build/package.py      # write dist/idlery-netlify.zip and dist/corecredit-netlify.zip
```

`build/verify.sh` runs the structural check, the WCAG contrast check, the content
and metadata sweep, and a headless-Chromium pass over every page at six viewport
widths, in light and dark, at two font sizes. All four must come back clean
before an archive is built.

Every page is self-contained static HTML and CSS: no web font, no CDN, no
analytics, no cookie, and — apart from one 52-line progressive-enhancement
script on the Idlery site — no JavaScript.

`brand/` holds the two pieces of Idlery artwork every derived asset comes from:
the 1024 × 1024 app icon, which is also the anchor for the site's whole colour
system, and the wordmark. `python3 build/make_brand_assets.py` regenerates the
marks, favicon, touch icon, manifest icons, wordmark and social card from them.
